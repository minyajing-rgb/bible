# From John to Jesus · Playing Cards Style Gate

Status: **Canonical production gate**

This document must be checked before generating any card face, card back, packaging, cotton-linen pouch, guidebook, print sheet, or product mockup for the `From John to Jesus` playing-card project.

## Canonical visual style — Style A

**Use this for all final / publishable assets.**

- White or cool-white background.
- Very fine black line drawing / minimalist editorial sketch.
- Large areas of clean negative space.
- One tiny warm accent only: muted warm gold / sand-gold / light warm brown.
- The warm accent is a highlight, never a full illustration wash.
- Most clothing, landscape, water, architecture and props remain black-and-white line art.
- Soft, quiet, restrained and contemporary; never heavy church-merchandise styling.
- No full-frame watercolor, no beige wash over the entire image, no dark luxury-gold Bible aesthetic.
- No photorealistic or cinematic rendering.
- No crowded e-commerce-poster composition for final product art.

## Canonical layout language

- Standard playing-card corner index and suit system.
- Consistent safe area and print bleed.
- Card face hierarchy must match the approved master layout before any batch is rendered.
- The sun / light motif may be used as the single warm accent.
- Typography must remain restrained and editorial.
- Suit mapping, verse reference and story order come from the canonical deck ledger, not from image-model improvisation.

## Production gate — mandatory before generation

Pass all six checks before rendering:

1. **Reference check** — compare against the existing canonical GitHub finals.
2. **Line check** — black fine-line drawing, not colored illustration.
3. **Accent check** — only one small warm accent; no overall pastel wash.
4. **Layout check** — use the approved playing-card / packaging system, not a generic promotional poster layout.
5. **Whitespace check** — preserve generous breathing room.
6. **Series check** — the new asset must look like it came from the same physical deck as the existing approved work.

If any check fails, do not mark the asset `final`.

## Style B — alternate / backup only

Soft-color line art (light beige, sage, pale blue, muted watercolor line work) may be retained for exploration, alternate edition, family edition, marketing mockups or backup art.

**Style B must never overwrite Style A canonical assets.**

Recommended folder split:

```text
playing-cards/
  style-a-canonical-monochrome/
  style-b-alternate-soft-color-line/
  packaging/
  guidebook/
  card-back/
  jokers/
  print-ready/
```

## Packaging application

The same Style A gate applies to:

- tuck box / paper box
- eco-friendly cotton-linen drawstring pouch
- instruction guide / folded leaflet
- card-back
- print-ready dielines

Packaging should feel like an extension of the cards: mostly white/natural material, black fine line work, and one restrained warm-gold light/sun accent.

## Content safety rule

Visual generation is downstream of the canonical research ledger. Never let an image model invent verse references, Gospel sequence, suit mapping, card count, textual variants, or historical claims.
