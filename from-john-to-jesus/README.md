## Historical baseline

The project does not claim access to autograph manuscripts or a text that is guaranteed to be untouched by transmission. It distinguishes:

1. Historical tradition
2. Gospel redaction
3. Scribal variant
4. Later interpretation

Greek quotations use the SBL Greek New Testament where applicable. Dates are broad scholarly working ranges, not claims of exact composition dates.
