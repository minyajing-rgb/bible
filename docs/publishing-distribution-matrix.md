# Publishing and Distribution Matrix

Status as of 2026-08-31. Platform access and API approval can change.

## Directly available now

| Destination | Current state | Deliverable |
|---|---|---|
| GitHub `minyajing-rgb/bible` | connected and writable | complete archive, ledgers, source notes, print files |
| From John to Jesus portal | deployed | public/private reading hub and evidence index |

## One connection enables the main international network

Connect Metricool to schedule/adapt content for Instagram, TikTok, X, Threads, Facebook, LinkedIn, Pinterest, and YouTube. Each account still requires its own authorization, and platform review/rate limits continue to apply.

Recommended packaging:

- Instagram: one 10-card chapter as one carousel.
- Pinterest: one evidence card per Pin, linking to the portal chapter.
- LinkedIn: 5–10 image document/carousel plus one source-method paragraph.
- X / Threads: 4–6 post evidence thread; do not dump all ten full notes into one post.
- TikTok / YouTube Shorts: 25–45 second narrated vertical sequence built from the ten cards.
- Facebook: carousel plus a question that invites source comparison rather than denominational conflict.

WordPress can be connected separately for long-form bilingual chapter pages and scheduled publishing.

## Vertical communities

These are distribution targets, not unattended broadcast endpoints:

- Christian / Bible: Faithlife groups, moderated Facebook groups, Christian Forums, denomination-specific communities.
- Academic Bible: Reddit `r/AcademicBiblical`, biblical-studies forums, manuscript and textual-criticism groups.
- Spirituality and visual storytelling: selected Reddit communities, Pinterest boards, Discord communities, Telegram channels, and Medium/WordPress publications.

Community posts require moderator-rule review and source-appropriate tone. Never mass-post identical copy or present disputed reconstructions as settled fact.

## Editorial rollout

1. Portal and GitHub are the canonical source of truth.
2. Publish Part I common-ground material first.
3. Introduce redaction examples after readers understand the shared Jordan core.
4. Introduce actual manuscript variants only with both readings and uncertainty.
5. Use the playing deck as a collectible discovery product that links back to the evidence archive.
